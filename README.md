# 讲谈社 · 兴亡的世界史 · 认知档案

> 我们必须摆脱已经成为常识的历史形象的束缚，设定新的历史舞台。

一个可以直接装进 AI 的**历史分析框架**——用《兴亡的世界史》九卷共享的方法看问题。

这不是提示词模板，也不是让模型复述这套书的内容。它注入的是这套丛书的**分析路径**：把"常识"当作研究对象而非出发点、悬置欧洲中心论、以跨区域网络而非孤立文明为单位、追问帝国留下什么而不只讲它如何灭亡。

区别在于：复述内容得到的是读书笔记；植入分析路径得到的是**处理一个没读过的对象时那套拆解方式**。

## 档案构成

| 部件 | 条数 | 质量约束 |
|------|------|----------|
| 基本立场 | 8 | 每条须在两卷以上得到印证，否则注明卷次 |
| 操作顺序 | 6 步 | 从"这个单位是否被当成理所当然"起到"标出不知道的部分"止 |
| 各卷独特切口 | 9 | 每卷一个可迁移的观察角度 |
| 学者之间的分歧 | 3 | 主要来自中文版推荐序对原作者的批评，保留不和稀泥 |
| 框架边界 | 5 | 明确划出这套书没覆盖什么 |

八条基本立场：

1. **"常识"是研究对象，不是出发点**——遇到"大家都知道"的历史判断，先问它何时形成、由谁形成、服务于什么
2. **欧洲中心论是必须悬置的默认设置**——包括不以另一个中心替换它
3. **看网络，不看孤岛**——问一个帝国"为什么强"之前，先问它处在什么网络里
4. **"兴亡"问的是留下什么**——灭亡只是中途，重点是遗产
5. **史料本身有立场**——先问谁写的、写给谁看、他站在哪一边
6. **民族国家不是历史的自然单位**——用现代国界回溯古代通常会产生假问题
7. **被征服者也有视角**——只有胜者叙述的那叫宣传
8. **明确说出不知道**——承认边界，别人才知道结论能用在哪儿

## 蒸馏方法

采用「仓颉 · 认知植入术」的四条铁律：

1. 没形成故事的信念不进
2. 没反思的决策不进
3. 不写 Step 1 / 2 / 3 这类推理步骤
4. 全部第一人称

第 3 条是关键。写推理步骤等于把模型本来就会的东西重新教一遍，占位置还没用。真正有价值的是那些**模型不可能从通用训练数据里知道的东西**——具体的人、具体的事、具体的失败。

**多作者丛书的特殊处理**：九卷作者各不相同，不存在统一人格。因此产出的不是"某人的思维"，而是**这套书共享的编辑方针 + 各卷各自的问题意识**。凡是标为"丛书共性"的判断，都在两卷以上得到印证；单卷主张注明卷次。

## 素材来源

九卷中文版的**框架性章节**：推荐序、序章/前言、终章/结束语/后记，以及第 2 卷的正文补读。

约 150 万字全文无法逐字处理，提取策略是抓取最能暴露方法论与结论的位置，再对材料偏少的卷补读正文。提取到的框架章节合计 187,275 字。

**中文版推荐序是重要材料**：每卷由中文学者撰写，直接概括该卷的方法论价值与局限，而且**包含对原作者的批评**（如姚大力对第 4 卷血统论的质疑、向荣对第 9 卷欧洲中心论的批评）。档案在引用时已区分作者主张与序作者评述。

**关于原始文本**：`references/source-text/` 下的 epub 解包全文受版权限制，未随仓库分发。档案中的引用以该解包文本为准，如需核对请自行获取书目并按同法解包，行号可能因版本而异。

## 质量自检

全部引文经脚本化批量溯源校验——对 `SKILL.md` 与 `references/` 中所有「」引文，做"去引号/去省略号后子串匹配解包源文本"的核对。两个核心文件共 131 条引文，全部可在源文本中定位。

校验中查出并修正了 18 处「概括表述被误加引号」（例如把原文「时间和空间的二重框架」简写成「时间、空间二重框架」）。另在 02/03 档案中写明引用规范：`「」` 既用于逐字原文引用，也用于**指称**被批判的通说、他人学说或概念名。

## 已知局限

- **选题性的，不是全覆盖**：九卷集中在中国、中亚、西亚、欧洲、俄罗斯、东南亚。**非洲、美洲、大洋洲、南亚基本缺席**。
- **普及读物，不是学术专著**：面向公众，配大量插图和人物小传。结论可以直接引用，但论证的完整度不如专门研究。
- **各卷厚度不均**，处理方式差异较大，不能假定九卷同一水准。
- **中文版是选本**，日文原版规模更大，中译有取舍。
- **叙述的当代关切很强**：多卷把古代与当代（9·11、伊拉克战争、欧盟、民族纷争）并置对话，读的时候要分清哪句是史证、哪句是借古论今。
